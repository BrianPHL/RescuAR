# Change records

Each task that modifies repository files has one dated record, following the
[documentation workflow](../contributing/documentation-workflow.md). Records cover
every logical change and link its current guide. Use a short entry for a small
change; do not duplicate an entire implementation or create one file per edit.

Records preserve what was changed and checked at that time. Consult the
[documentation index](../README.md) for current setup and operating guidance.

| Date (Asia/Manila) | Record | Scope |
| --- | --- | --- |
| 2026-11-03 | [Agent guidance and UI reference](2026-11-03-agent-guidance-and-ui-reference.md) | Documentation workflow, visual baseline and scoped design confirmation |
| 2026-11-03 | [Documentation alignment](2026-11-03-documentation-alignment.md) | Retrospective record of committed audit corrections, `15222e5` |

Add later records here in newest-first order. Unrelated tasks on the same date
use distinct descriptive filenames. Follow-ups to the same task update its record.
