# Change records

Each task that modifies repository files has one dated record, following the
[documentation workflow](../contributing/documentation-workflow.md). Records cover
every logical change and link its current guide. Use a short entry for a small
change; do not duplicate an entire implementation or create one file per edit.

Records preserve what was changed and checked at that time. Consult the
[documentation index](../README.md) for current setup and operating guidance.
