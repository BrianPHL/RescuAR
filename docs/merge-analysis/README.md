# Historical integration evidence

Files here record the October 26–28 Dev/Athena integration and its then-current
source decisions, repairs and validation. They are not current setup instructions
or proof of the behavior of a later revision.

Use the [project documentation index](../README.md) for current task routes and
the [catalog's historical section](../catalog.md#historical-evidence) to locate
reports. The JSON baselines and CSV decisions preserve paths/hashes at capture
time; do not rewrite them to match a later checkout or move referenced files as
part of a cosmetic documentation reorganization.

Corrections should be explicitly dated and preserve the original evidence.
Current changes belong in [task records](../changes/README.md), with detailed
new investigation evidence in the appropriate documentation area.
