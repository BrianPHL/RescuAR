# Shared historical-event context

These files capture supporting information from the uploaded Espina paper and Marikina City Ecological Profile.

They are **not independent flood-extent ground truth**. Use them for event characterization, data cross-checks, and future hydrologic/exposure improvements.

- `espina_historical_river_levels.csv` — historical Marikina River levels reported for Ondoy, Pedring, and Habagat.
- `espina_tumana_household_flood_reference.csv` — Tumana survey evidence for combined Ondoy/Habagat impacts.
- `ecological_profile_population_2020.csv` — 2020 barangay population, household, land-area, and density data.
- `ecological_profile_city_context.csv` — citywide elevation, slope, river, population, and age context.
- `ecological_profile_flood_hazard_inventory_2018.csv` — MCDRRMO administrative flood-hazard flags by barangay.

The 2020 population/density data must not be substituted for historical 2009/2013 demographics in event-specific population validation.
